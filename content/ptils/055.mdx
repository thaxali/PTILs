## Why It Works

Practice SQL without setting up a database. The AI maintains consistent data across queries so you can practice joins, aggregations, and subqueries in a realistic flow.

## Example Output

```
SELECT u.name, COUNT(o.id) as orders
FROM Users u JOIN Orders o ON u.id = o.user_id
GROUP BY u.name ORDER BY orders DESC LIMIT 3;

| name          | orders |
|---------------|--------|
| Alice Chen    | 47     |
| Bob Smith     | 31     |
| Carol Davis   | 28     |
```
