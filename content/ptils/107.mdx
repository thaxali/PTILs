## Why It Works

Describing expected vs. actual behavior is the foundation of debugging. The AI reads your code with fresh eyes, unclouded by the assumptions that caused the bug.

## Example Output

**Bug found on line 12:**
```js
// You wrote:
if (user.role = 'admin')
// Should be:
if (user.role === 'admin')
```

**Why:** Single `=` is assignment, not comparison. This always evaluates to truthy, so every user gets admin access. Use `===` for strict comparison.
