## Why It Works

Visual representations of algorithms make abstract concepts concrete. Seeing the data change state at each step builds intuition that code alone can't.

## Example Output

**Bubble Sort — Step by Step:**

[5, 3, 8, 1] → Compare 5,3 → swap
[3, 5, 8, 1] → Compare 5,8 → no swap
[3, 5, 8, 1] → Compare 8,1 → swap
[3, 5, 1, 8] → Pass 1 complete. Largest (8) is now at end.
