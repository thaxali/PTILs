## Why It Works

Security is often an afterthought. This prompt forces a systematic review of your data flow and surfaces vulnerabilities you might not have considered.

## Example Output

**Critical findings:**

1. API keys stored in plaintext in .env committed to git — rotate immediately and add to .gitignore
2. No rate limiting on login endpoint — add brute-force protection
3. User data transmitted over HTTP in staging — enforce HTTPS everywhere...
